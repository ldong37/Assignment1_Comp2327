# Intermediate Software Development Automated Teller Project

This project will be developed over the course of several assignments.  Each assignment will build on the work done in the previous assignment(s). Ultimately, an entire system will be created to manage bank transactions for clients who have one or more bank accounts.

## Author

Dong Le Quoc Bao


Assignment 1 is all about classes, encapsulation, and unit testing. The goal is to build a few foundational classes that later assignments will build on top of.

The classes in this assignment are:

- `AccountStatus` – an enum for the different states a bank account can be in.
- `Client` – represents a customer of the bank.
- `BankAccount` – represents a bank account and its basic operations (deposit, withdraw, etc.).
